# UNSLOP — правила UI для Lite Stream Browser

Этот файл обязателен для любого изменения `ui/index.html` и любого нового UI-кода.
Стек проекта: **Rust + Tauri v2 + WebView2 + vanilla HTML/CSS/JS**. Сборщика фронтенда
и UI-фреймворков нет и быть не должно.

## 1. Запрещённый «AI-slop»

- Никаких дефолтных фиолетово-синих градиентов (`from-indigo-500 to-purple-600`),
  градиентного текста в заголовках и «магических» фиолетовых акцентов.
- Никаких декоративных WebGL/Canvas-шейдеров, частиц, параллакса, тяжёлых 3D-анимаций.
- Никаких размытых неоновых теней, «светящихся» обводок и `shadow-lg` на каждой карточке.
- Никаких пустых маркетинговых hero-секций, огромных заголовков ради заголовков и
  обещаний, которые не подтверждены кодом.
- Не подключать React/Vue/Svelte, Tailwind CDN, анимационные библиотеки (GSAP, Framer
  Motion, Lottie) и иконочные шрифты. Иконки — только inline SVG.

## 2. Эстетика нативного десктоп-лаунчера (Linear / Raycast / Arc)

- Базовый фон: `#0B0C0E`.
- Поверхности и карточки: `#111215`.
- Приподнятые элементы и hover: `#181A1F` / `#1F2228`.
- Границы: `1px solid rgba(255, 255, 255, 0.08)`, на hover/focus —
  `1px solid rgba(255, 255, 255, 0.16)`. Никаких толстых рамок и градиентных бордеров.
- Акценты строго функциональные:
  - YouTube — `#FF0033`; Twitch — `#9146FF`;
  - используются только как маркер платформы/активной вкладки/иконки;
  - весь остальной UI монохромный.
- Функциональные статусы (успех/сон/ошибка) — приглушённые `#5ED68A`, `#E0B25C`,
  `#FF6B6B` и только в виде точек, чипов и тонких линий.
- Типографика: системный UI-шрифт без засечек, базовый размер 13 px.
  Моноширинный шрифт — только для метрик RAM/CPU, таймеров, путей, токенов и
  горячих клавиш. Для чисел обязательно `font-variant-numeric: tabular-nums`.
- Плотность: сетка 4/8 px, компактные отступы, без «воздушных» пустот.

## 3. Zero-Bloat и производительность (Tauri v2 / WebView2)

- Анимации только через `transform` и `opacity`, длительность `150–220 ms`,
  easing `cubic-bezier(0.2, 0, 0, 1)`.
- Не анимировать `width`, `height`, `top`, `left`, `box-shadow`, `filter`, `background`.
- При `body.compact`, гибернации вкладки и `document.hidden` все CSS-анимации
  ставятся на паузу (`animation-play-state: paused`). JS-таймеры метрик и
  spotlight останавливаются.
- Никаких `backdrop-filter: blur(...)` на больших площадях и постоянных фоновых
  перерисовок. Spotlight карточек двигается через `transform`.
- Уважать `prefers-reduced-motion: reduce`.

## 4. Архитектурные инварианты, которые нельзя ломать

- Одновременно живёт **максимум один** дочерний WebView активной вкладки.
  Переключение вкладки усыпляет предыдущую — это ядро экономии RAM.
- Высота панели — `36 px`: `PANEL_HEIGHT` в `src-tauri/src/browser.rs` и `--bar`
  в `ui/index.html` обязаны совпадать.
- Все существующие Tauri-команды сохраняются:
  `get_state`, `open_tab`, `switch_tab`, `close_tab`, `navigate`, `go_back`,
  `reload`, `hibernate`, `wake`, `import_twitch_token`, `toggle_compact`,
  `toggle_always_on_top`, `open_extensions_folder`, `list_extensions`.
- Дочерний WebView рисуется поверх основного. Любой HTML-диалог ниже панели
  должен сначала скрыть активный WebView командой `set_webview_visible`.
- `invoke(...)` вызывается только из UI; ошибки показываются тостом, а не
  `alert()`/`confirm()`.
- Импорт Twitch-токена не логируется и не сохраняется в `localStorage`:
  в хранилище попадает только факт импорта, дата и имена cookie.

## 5. Обязательный чек-лист перед сдачей

- [ ] Нет фиолетово-синих градиентов, неона, glow-теней и декоративных шейдеров.
- [ ] Палитра и границы соответствуют разделу 2.
- [ ] Все анимации — `transform`/`opacity`, пауза в compact/sleep/hidden.
- [ ] `cargo check` проходит; ошибок в консоли WebView нет.
- [ ] Работают: открытие YouTube/Twitch, переключение вкладок, сон/пробуждение,
      `Ctrl+H`, `Ctrl+Tab`, импорт Twitch-токена, список расширений, настройки.
- [ ] Новые UI-элементы имеют `aria-label`/`title` и доступны с клавиатуры.
